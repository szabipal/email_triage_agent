## Current Behavior

Gmail sync imports up to `EMAIL_AGENT_GMAIL_SYNC_LIMIT` messages matching
`EMAIL_AGENT_GMAIL_SYNC_QUERY`, currently intended to default to 10 unread
messages. Imported messages are deduplicated by Gmail message ID.

The LLM receives the normalized subject and a capped normalized body, not the
raw MIME message, full headers, attachments, or raw HTML.

When Gmail label writing is enabled, successful analyses can apply labels such
as:

- `AI/Billing`
- `AI/Security`
- `AI/Newsletter`
- `AI/Jobs`
- `AI/Promotion`
- `AI/Action Required`
- `AI/Calendar`

## Local Setup Notes

Private runtime files are intentionally ignored:

- `.env`
- `secrets/`
- `data/`
- `real-email-smoke/`

To enable Gmail label writing locally:

```bash
rm -f data/gmail_token.json
```

Then set:

```text
EMAIL_AGENT_GMAIL_LABEL_WRITE_ENABLED=true
```

Restart the backend and click **Sync Gmail** to re-authorize with Gmail modify
permissions.
