# Step 2 — Define User Stories

## Prompt

Using the project scope specification, define the main user stories for the email triage system.

Focus on observable user behavior rather than implementation details.

Cover at minimum:

- viewing a reduced/prioritized inbox
- seeing concise summaries
- seeing categories
- identifying emails that require action
- identifying deadlines
- understanding why an email was marked high priority
- configuring important senders/categories/preferences
- viewing relevant historical context
- receiving a proposed calendar event
- approving or rejecting a calendar write

Use the format:

```text
US-01
As a [user],
I want [capability],
so that [benefit].
```

For every user story, include acceptance criteria using explicit testable statements.

Example:

```text
Given ...
When ...
Then ...
```

Separate critical V1 stories from optional future stories.

Do not describe implementation technology yet.
