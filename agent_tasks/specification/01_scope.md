# Step 1 — Define Project Scope

## Prompt

Create the initial scope specification for an AI-powered email triage and prioritization system.

The system's primary purpose is to reduce the amount of manual attention required to manage an email inbox.

The intended capabilities are:

- email summarization
- email categorization
- spam/newsletter/low-value message detection
- action-required detection
- deadline and meeting extraction
- user-specific prioritization
- retrieval of relevant historical email context using RAG
- explanations for categorization and priority decisions
- a simple user interface
- proposed calendar actions
- user-approved calendar writes through an external API

Do not design the implementation yet.

Produce:

1. Project objective
2. Primary user
3. Core problem being solved
4. In-scope capabilities
5. Explicit non-goals for V1
6. Assumptions
7. High-level success criteria

Keep V1 small enough to be built and evaluated as a portfolio project.

Explicitly place the following outside V1 unless needed for the core architecture:

- automatic email sending
- autonomous deletion or archiving
- complex multi-agent architecture
- Slack integration
- voice interface
- knowledge graphs
- fine-tuning custom models
- full production authentication system
- automatic continuous inbox monitoring

Do not write code.
